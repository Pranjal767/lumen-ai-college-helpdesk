# Reservation Policy Summary
Percentages below are illustrative summaries based on the Maharashtra State reservation framework; the CET Cell notification prevails.

| Category | Reservation |
|---|---|
| SC | 13% |
| ST | 7% |
| VJ (A) | 3% |
| NT (B) | 2.5% |
| NT (C) | 3.5% |
| NT (D) | 2% |
| OBC | 19% |
| SBC | 2% |
| SEBC | 10% |
| EWS | 10% |

Horizontal reservations: Women 30%, PwD 5%, Defence 5%, Orphans 1%.

## Seat Types in CAP
- Home University (HU), Other Than Home University (OHU), State Level (SL), All India (AI).
- TFWS seats: for candidates whose family annual income is up to Rs. 8,00,000 (see Fees).
- Minority quota: not applicable at AIT (non-minority institute).

## Candidature
Maharashtra State candidature requires HSC and SSC from Maharashtra, or domicile certificate and other conditions as per CET Cell.
