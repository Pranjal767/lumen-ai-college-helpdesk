# Grievance and Safety

- **Anti-Ragging:** zero tolerance. Helpline 1800-180-5522 (UGC). College squad: Dr. Smita Joshi, anti-ragging@aurora-tech.example.

- **Student Council:** elected representatives of each class meet the Principal on the first Saturday of each month.
