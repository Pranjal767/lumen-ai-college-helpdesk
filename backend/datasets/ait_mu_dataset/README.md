# AIT (Aurora Institute of Technology, Vashi, Navi Mumbai) - Imaginary MU-affiliated College Dataset v2
All data is fictional. It is modeled on the structure of colleges affiliated to the University of Mumbai
(MHT-CET/CAP admissions, MU-style exams, local train concession, Indradhanushya, Avishkar, etc.).
Numbers (fees, cutoffs, rules) are illustrative; verify against real circulars if you present them as real.

Folders map to the problem statement: 1_admissions, 2_fees, 3_examinations, 4_timetable_calendar, 5_activities_events.
- Each .md has a metadata header (title, category, department, date).
- Recency tests: fee_07 (15 Jan 2027) supersedes fee_08 (31 Dec 2026).
- Detailed answer guides: adm_11–adm_13 cover the FE CAP sequence, candidate-specific document checklists, and Freeze / Float / Slide / institute-level choices; fee_11–fee_13 provide worked cost examples, concession calculations, payment, and clearance workflows.
- events_calendar.csv: structured list of upcoming events.
- test_questions.csv: expected answers incl. "should-refuse" questions.
"Today" in the data is about 20 November 2026.
